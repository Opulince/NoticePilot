# NoticePilot

From information to action.

Scan a school circular and NoticePilot turns it into verified tasks and calendar events. On-device OCR reads the
text, Gemini extracts the items, and a deterministic verifier checks every item against the scanned text before
it reaches your calendar. Anything it can't verify is flagged for you to check.

Built for InnoHack 2026 by Advay Srivastava, Siva Shanmukam and Khaled Faiyaz Rawoot.
